# ◼ ПРОРЫВ — лаунчер zapret-discord-youtube

Минималистичное приложение на русском: скачивает официальный запрет с GitHub,
распаковывает, включает, подбирает лучшее подключение и сам обновляется.

Дизайн: чёрно-белый минимализм, векторные SVG-иконки (`assets/icons/`),
логотип-плашка с «П», шрифты **Unbounded** (заголовки) + **Manrope** (текст)
с кириллицей. Перерисовки только по изменениям — ничего не моргает,
в простое нагрузка CPU нулевая.

## Быстрый старт (для тебя)

1. Установи Python 3.10+ (с галочкой Add to PATH)
2. Двойной клик по **`run.bat`** — всё установится и запустится само.
   Шрифты доустановятся автоматически (при запуске от администратора),
   либо запусти `install_font.bat`.

Готовый exe уже собран: **`dist\Proryv.exe`**.
Готовый установщик для друзей: **`installer\Output\ProryvSetup.exe`**.

## Кнопки

- **Установить** — скачивает последний релиз https://github.com/Flowseal/zapret-discord-youtube
  (.zip с GitHub API), распаковывает в `%LOCALAPPDATA%\PRORYV\zapret`,
  сохраняет пользовательские списки `*-user.txt`.
- **Включить / Остановить** — запуск выбранной стратегии (`general*.bat`)
  или остановка `winws.exe` + служб.
- **Автоподбор** — по очереди включает каждую стратегию, меряет
  YouTube / Discord / Google / Cloudflare / Steam и оставляет лучшую включённой.
- **В автозапуск** — ставит стратегию как службу Windows `zapret` (как `service.bat → Install Service`).
- **Галка «Автообновление»** — при старте проверяет релиз на GitHub, при новой версии
  скачивает и переустанавливает автоматически + показывает белый баннер.

> Запуск обхода требует **прав администратора** (WinDivert).
> Запусти `run.bat` / `Proryv.exe` правой кнопкой → «Запуск от имени администратора».
> Добавь папку запрета в исключения антивируса (ложное срабатывание на WinDivert — это нормально,
> так и пишет сам автор запрета).

## Сборка .exe (для себя)

```
build_exe.bat
```
Получишь `dist\Proryv.exe` (один файл, с запросом UAC-админа, с иконкой).

## Загрузчик (Inno Setup)

Установщик уже скомпилирован: `installer\Output\ProryvSetup.exe`.
Он требует админа, кладёт exe в Program Files\PRORYV, **ставит шрифты**,
делает ярлык в меню Пуск (и на рабочий стол — по галке), на русском языке.

Пересобрать после изменений:
```
build_exe.bat
installer\build_installer.bat
```
(`build_installer.bat` сам найдёт ISCC; если Inno Setup нет —
скачай с https://jrsoftware.org/isdl.php)

## Структура

```
run.bat / run_app.py      — запуск
app/config.py             — пути, тема, цели проверки
app/zapret_manager.py     — GitHub, скачивание, службы, автоподбор
app/main.py               — чёрно-белый GUI (иконки, логотип, шрифты, без моргания)
app/icons.py              — векторные иконки: рендер в PNG + экспорт в SVG
app/fonts.py              — Unbounded/Manrope: скачивание, автоустановка в систему
assets/icons/*.svg        — исходники иконок (логотип, скачать, плей, стоп, ...)
assets/fonts/*.ttf        — шрифты с кириллицей
requirements.txt          — requests, psutil, pyinstaller, pillow
build_exe.bat             — сборка exe
install_font.bat          — ручная установка шрифтов
installer/ProryvSetup.iss — установщик для друзей
```

Данные хранятся в `%LOCALAPPDATA%\PRORYV\` (zapret + data.json + лог).
